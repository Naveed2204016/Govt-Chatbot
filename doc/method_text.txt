Proposed Methodology

This study investigated four approaches to Bangla government-service question answering: prompt-based inference, supervised fine-tuning, retrieval-augmented generation (RAG), and RAG combined with fine-tuning. The comparison examined how demonstrations, domain-specific training, and access to external information affected answer generation. The task covered passport and e-passport services, National Identity (NID) services, birth and death registration, and Taxpayer Identification Number (TIN) services.

System Overview

The framework comprised instruction-tuned language models, a domain-specific question-answer dataset, and an external government-service knowledge base. Training question-answer pairs supported supervised adaptation and provided demonstrations for few-shot prompting. The knowledge base supplied evidence for retrieval-based inference. Held-out questions were used for evaluation, and their reference answers were withheld from test prompts.

Prompt-based and standalone fine-tuned models answered questions without retrieval. In the RAG approach, the system retrieved relevant passages from the knowledge base and supplied them to the generator alongside the question. The combined approach used the same retrieval process with a fine-tuned generator. Comparing these approaches allowed us to examine the contributions of domain adaptation and external evidence. Model choices, numerical configurations, computing resources, and evaluation settings are reported in the Experimental Setup section.

Prompt-Based Inference

Zero-shot prompting assessed the ability of each pretrained instruction-tuned model to answer government-service questions without demonstrations, domain-specific fine-tuning, or retrieved evidence. The prompt requested a concise Bangla response addressing the information sought by the user, such as application procedures, required documents, or fees.

Few-shot prompting supplied example questions and answers before the test question. These demonstrations illustrated the expected language, content, and response style without updating model parameters. Few-shot chain-of-thought prompting extended this approach by requesting a brief analysis followed by a final answer. Evaluation focused on the final response.

Supervised Fine-Tuning

Supervised fine-tuning adapted the generators to the terminology and response patterns of Bangla government-service question answering. Training examples were represented as conversations containing a system instruction, a user question, and a reference answer. Additional input accompanied the question where available. Each conversation followed the corresponding model's instruction format, and training used an autoregressive language-modeling objective.

We used quantized low-rank adaptation (QLoRA) to reduce the memory required for training. The pretrained backbone remained frozen in quantized form, while low-rank adapters learned task-specific updates. Each adapted layer combined its frozen weight with a scaled low-rank update. This approach enabled domain adaptation without updating all backbone parameters. The resulting generators were evaluated both independently and with retrieved context.

Retrieval-Augmented Generation

Knowledge Representation

The curated knowledge base was divided into overlapping passages so that relevant information could be retrieved at a finer level than complete documents. Overlap preserved context across passage boundaries. Passage representations incorporated the document title, topic, and content, while document identifiers, service-domain labels, and source URLs were retained for attribution.

Hybrid Retrieval

The retrieval pipeline combined dense semantic retrieval with sparse lexical retrieval. Dense retrieval represented questions and passages in a shared embedding space and ranked passages by similarity to the question. Sparse retrieval used BM25 to identify passages containing relevant terms. Combining these methods allowed retrieval to consider both semantic similarity and explicit lexical matches, including administrative terms and numerical expressions.

Candidate retrieval was restricted to the service domain supplied with each question. The framework therefore assumed that the service category was available at inference time; automatic domain classification was not part of this pipeline.

Rank Fusion and Reranking

Dense and sparse rankings were combined using reciprocal rank fusion. Each passage received contributions based on its position in the retrieval lists, and the combined score determined which candidates proceeded to reranking. A reranker then assessed each question-passage pair jointly to refine relevance ordering. The highest-ranked passages formed the evidence context for answer generation.

Context-Grounded Generation

The generator received the question together with the titles and contents of the selected passages. Its instruction requested a concise Bangla answer based on the supplied evidence, with attention to fees, numerical values, processing times, and required documents. When the context did not contain sufficient information, the model was instructed to acknowledge that limitation.

The same retrieved passages were supplied to the different generators for each question. This kept the evidence consistent when comparing their answers.

Combining Retrieval with Fine-Tuning

The combined approach first adapted each generator using the training question-answer pairs and then supplied retrieved evidence during inference. The retriever and reranker remained fixed; fine-tuning affected the generator alone. Domain-specific training provided supervision on answer content and response patterns, while retrieval supplied external information relevant to the current question.

Comparisons with standalone fine-tuning examined the contribution of retrieved evidence. Comparisons with RAG using the pretrained generator examined the contribution of domain-specific adaptation under the same retrieved context. All approaches were evaluated against held-out reference answers using the measures described in the Experimental Setup section.
